# Overlay symbol collisions

Generated by `tools/scripts/overlay_symbol_collisions.py --write` from the built
overlay objects (`make overlay-build-all`) and `build/USA/main.elf`. Do not edit.

A single-executable port needs unique global names. A name defined by two or
more overlays is `identical` when section kind, size, bytes (relocated words
masked) and relocation targets agree - one shared definition serves them all -
and `conflicting` otherwise. Rules for resolving the conflicting names are in
`docs/CONVENTIONS.md` (Overlays).

## Conflicting, private to an overlay

## Conflicting, room interface

Each overlay defines the name and a source shared by several overlays (`src/overlays/room_lib`, `include/pe1`) refers to it. Add it to `include/pe1/room_interface.h` and suffix its symbol-file entries with `__<overlay>` (docs/CONVENTIONS.md, Overlays).

None.

## Conflicting, also a main symbol

`sym.main.txt` places a main symbol inside the overlay window; main-only names belong in `configs/USA/sym.main_only.txt`.

None.
